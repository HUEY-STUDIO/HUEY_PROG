# 국내 건축 대지 법규 자동 조회 프로그램

대한민국 주소를 입력하면 해당 대지의 **대지개요**(용도지역·지목·면적)와
적용되는 **국가법령**(건축법·국토계획법) 상 건폐율/용적률 상한, 그리고
관련 **지자체 조례 후보**를 자동으로 모아 보여줍니다.

국토교통부 [토지이음](https://www.eum.go.kr/)이 제공하지 않는
**지자체 조례 연결**이 이 프로젝트의 차별점입니다.

> ⚠️ **면책**: 건폐율·용적률 산정값은 국토계획법 시행령이 정한 **법정 상한**이며,
> 실제 적용값은 지자체 도시계획조례로 이 범위 안에서 따로 정해집니다.
> 조례 검색 결과는 자동 판정이 아니라 **검토 후보**입니다.
> 인허가 판단의 최종 근거로 사용하지 마세요.

## 파이프라인

```
주소 입력
  │
  ├─ 1단계  도로명주소 API ──────────→ 법정동코드 + 지번 → PNU(19자리)
  │          브이월드 Geocoder ───────→ 경위도
  │
  ├─ 2단계  국가공간정보포털(NSDI) ───→ 토지이용계획(용도지역/지구)
  │                                   토지특성(지목·면적·공시지가)
  │
  ├─ 3단계  국토계획법 시행령 84·85조 → 건폐율/용적률 법정 상한
  │          + 대지면적 ─────────────→ 건축면적·연면적 상한 산정
  │          국가법령정보 API ────────→ 근거 조문 링크/발췌
  │
  └─ 4단계  자치법규 API ────────────→ 지자체 조례 후보 (링크)
```

## 빠른 시작

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # 서비스키 입력 (docs/API_KEYS.md 참고)

uvicorn app.main:app --reload
```

- API 문서: http://127.0.0.1:8000/docs
- 상태 확인: http://127.0.0.1:8000/health

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/health` | 서비스 상태 + 인증키 설정 여부 |
| `GET` | `/api/v1/address/search?q=` | 주소 검색 → 후보 목록 + PNU |
| `GET` | `/api/v1/site?address=` | **종합 조회** (대지개요 + 상한 + 조례 후보) |
| `GET` | `/api/v1/site/pnu/{pnu}` | PNU 직접 조회 |
| `GET` | `/api/v1/limits` | 용도지역 21종 법정 상한 전체 표 |
| `GET` | `/api/v1/limits/estimate?zone=&area_m2=` | 용도지역 + 면적 → 최대 규모 산정 |
| `GET` | `/api/v1/ordinances?sido=&sigungu=` | 지자체 조례 후보 검색 |

`/api/v1/site` 주요 파라미터

- `candidate_index` — 주소 후보가 여러 건일 때 사용할 번호 (기본 0)
- `with_statute_content` — 법령 조문 **본문**까지 조회 (호출 6건 추가, 기본 `false`)
- `include_ordinances` — 조례 검색 포함 여부 (기본 `true`)

## 설계 노트

**용도지역 정규화** — LURIS/토지이음 응답의 용도지역 표기는 편차가 큽니다
(`제2종일반주거지역`, `2종일반주거`, `제2종일반주거지역(7층이하)`, `제Ⅱ종…`).
`domain/zoning.py` 가 괄호 부가설명 제거 → 종 표기 통일 → 별칭 사전 대조 →
최장 부분일치 순으로 정규화합니다.

**응답 파서의 내구성** — 공공데이터포털 계열 API 는 서비스마다 래퍼 키가
다릅니다(`landUses.field`, `response.body.items.item`, 단건일 때 리스트 대신 dict).
고정 경로 대신 JSON 을 훑어 레코드 배열을 찾는 방식으로 파싱합니다.

**부분 실패 허용** — 4개 외부 서비스 중 일부가 실패해도 나머지로 결과를 만들고
사유를 `warnings` 에 담아 반환합니다. 좌표 변환 실패나 법령 API 장애가
대지개요 조회를 막지 않습니다.

**호출 한도 대응** — LURIS 개발계정은 일 1,000건, 브이월드 지오코더도 일별
제한이 있습니다. `CACHE_TTL_SECONDS`(기본 1시간) TTL 캐시로 반복 조회를 줄입니다.
다중 워커 운영 시에는 Redis 등으로 교체하세요.

**인증키 형태 자동 보정** — 공공데이터포털은 같은 키를 Encoding/Decoding 두
형태로 제공합니다. Encoding 값을 넣으면 `%2B` 가 `%252B` 로 이중 인코딩되어
인증에 실패하는데, 어느 쪽을 넣어도 동작하도록 설정 단계에서 정규화합니다.

## 알려진 한계 / 다음 단계

- [x] 1단계: 주소 → 지번·좌표 변환
- [x] 2단계: 대지개요(용도지역·지목·면적) 자동 표시
- [x] 3단계: 건폐율·용적률 **법정 상한** 자동 계산
- [x] 4단계: 관련 조례 검색 결과를 링크로 제공
- [ ] **조례 조문 구조화** — 지자체별로 조문 구조·표현이 제각각이라
      "이 대지에 이 조항이 적용된다"의 완전 자동 판정은 도메인 규칙화가 필요합니다.
      서울 일부 구부터 시작해 자동 계산 범위를 넓히는 단계적 접근을 권장합니다.
- [ ] **둘 이상의 용도지역에 걸친 대지** — 현재는 대표 용도지역 1개를 고르고
      `warnings` 로 알립니다. 국토계획법 제84조의 면적 안분 계산은 미구현입니다.
- [ ] **건축물대장 연동** — 기존 건축물이 있는 대지의 현황(건폐율/용적률 소진분)
      비교. `BLDRGST_BASE_URL` 설정만 준비되어 있고 서비스 모듈은 미구현입니다.
- [ ] **PostgreSQL + PostGIS** — 현재는 인메모리 캐시만 사용합니다.
- [ ] **React 프론트엔드 + 지도** — 백엔드 API 우선 구현.

### 검증에 대해

각 공공 API 의 **정확한 요청 경로와 파라미터는 발급 후 받는 '활용가이드'와
반드시 대조 확인하세요.** 이 저장소의 기본 엔드포인트는 공개 문서 기준이며,
운영 주체가 경로를 바꿀 수 있어 전부 `.env` 로 교체 가능하게 해 두었습니다.

조회 결과는 [토지이음](https://www.eum.go.kr/)에서 같은 지번을 열람해
교차검증(cross-check)하는 것을 권장합니다. 응답의 `references` 필드에
해당 링크가 포함됩니다.
